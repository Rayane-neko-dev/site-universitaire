# University Website

A **Django-based university web application** featuring dynamic content management, responsive front-end design, and an **Observer Design Pattern** implementation for newsletter subscriptions.

---

## Features

- **University Information Management**
  - Actuaity,Agenda,Faculties, departments,scolarships,work oportunities, formations, specialities, semesters, and courses.
- **Newsletter System (Observer Pattern)**
  - Subscribers are notified of new updates via the Observer design pattern.
- **Responsive Front-End**
  - HTML, CSS, SCSS, and JavaScript.
  - Built upon a free responsive HTML template, fully customized for university needs.
- **Dynamic Back-End**
  - Powered by Django’s ORM and template system.
- **Reusable Components**
  - Centralized `base.html` for consistent layout.
  - Modular apps for different university entities.

---

##  Tech Stack

**Backend**
- [Django](https://www.djangoproject.com/) – Web framework for rapid development

**Frontend**
- HTML5, CSS3, SCSS, JavaScript (Vanilla)
- Bootstrap 
- **Observer Pattern** – Used for newsletter subscriptions and notifications.
